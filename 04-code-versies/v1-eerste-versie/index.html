Hallo! Ik ben Sofiane Berkani en ik studeer Graduaat programmeren aan Thomas More in Antwerpen. Ik ben een gemotiveerde IT-student met een sterke interesse in computers en technologie, en dit portfolio is mijn eerste stap op het web.

Over mij

Ik ben iemand die niet snel opgeeft. Als iets niet meteen lukt, blijf ik zoeken tot ik begrijp waarom. Naast mijn studie werk ik als Cybersecurity Analyst bij Argenta, waar ik kwetsbaarheden in systemen analyseer en opvolg.

In mijn vrije tijd volg ik graag sport, vooral voetbal en Formule 1, en houd ik mijn conditie op peil met fitness.

Waarom programmeren?

Programmeren geeft me de kans om echt iets te maken: van een idee in mijn hoofd naar iets dat werkt op een scherm. Ik vind het vooral leuk dat je met code problemen kan oplossen en dingen kan automatiseren.

Wat ik aan het leren ben

Ik werk met C#, JavaScript, HTML en CSS, en momenteel verdiep ik me in Docker en TypeScript. Voorbeelden van mijn werk vind je op GitHub. Meer info over HTML vind je op de MDN Web Docs.

Mijn doelen

Na mijn opleiding wil ik graag aan de slag in de IT-sector, in een team waar ik elke dag kan bijleren. Dit portfolio ga ik verder uitbreiden met projecten die ik maak.
